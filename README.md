# Prompt Builder

A single-page, deterministic prompt-design workspace. Enter a goal and its
context on the left, choose a prompt variant in the center, and inspect the
portable JSON brief live on the right.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The deterministic compiler
is in `lib/prompt-builder.ts`; it has no provider API dependency.

The companion Python MCP server is in `../prompt_builder_mcp`.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
